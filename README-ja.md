# BSD Trek — macOS Terminal版

NetBSDが公開するBSD Games系列のTrekを、元のCソースを使って
macOSのTerminal向けに移植したものです。ゲーム画面・コマンドは原作の英語です。
zshはビルドと起動に使い、ゲーム本体はCのままです。

## 起動

1. `trek-macos.zip` をダウンロードし、Finderで展開します。
2. Apple Command Line Toolsを入れていない場合は、Terminalで次を実行します。

   ```zsh
   xcode-select --install
   ```

   表示された案内に従ってインストールを完了してください。
   すでに入っていれば、この手順は不要です。Xcodeアプリ全体は必要ありません。

3. 展開先が「ダウンロード」フォルダなら、Terminalで次を実行します。

   ```zsh
   cd ~/Downloads/trek-macos
   zsh ./run-trek.zsh
   ```

   初回にCソースをコンパイルし、そのままゲームを起動します。
   2回目以降は、ソースに変更がなければ再コンパイルしません。
   別の場所へ展開した場合は `cd` のパスを変更してください。

Intel MacとApple Silicon Macは、それぞれのMac上で同じソースからビルドします。
Homebrew、Python、ネット接続はプレイに必要ありません。
ZIPには他のOSで作った実行ファイルを入れていません。

Finderから起動する場合は `Trek.command` を開けます。
権限エラーの場合は、上のTerminalでの起動方法を使ってください。

## 最初の設定

```text
Press return to continue.  → Returnキー
What length game:         → short
What skill game:          → novice
Enter a password:         → 任意の半角英数字（例 captain）
```

ここでのパスワードはゲーム内の自爆確認用です。MacやApple IDのパスワードは不要です。
長さは `short` / `medium` / `long`、難易度は `novice` / `fair` / `good` /
`expert` / `commodore` / `impossible` から選べます。

使命は、連邦の時間が尽きる前に銀河内のKlingon艦を全滅させることです。
8×8のquadrant（宙域）それぞれが10×10のsector（区画）に分かれます。
座標は0始まりで、最初の数値が上から下への行、次が左から右への列です。
状態表示の `3,6/7,3` は「宙域3,6／区画7,3」を表します。

## 基本コマンド

`Command:` に入力します。半角小文字を使ってください。
コマンド名だけを入力すると、必要な値を順に尋ねられます。
`?` はその入力欄で使用できる選択肢を表示します。

| 入力例 | 意味 |
|---|---|
| `srscan` または `s` | 現在の宙域の詳細表示 |
| `status` または `st` | エネルギー・魚雷・残り時間など |
| `lrscan` または `l` | 周囲の宙域をスキャン |
| `computer chart` | 調査済みの銀河マップ |
| `computer trajectory` | 現宙域の敵艦への針路と距離 |
| `computer course /3,7` | 現宙域の区画3,7への針路計算 |
| `computer course 2,4/5,5` | 宙域2,4の区画5,5への針路計算 |
| `computer move 2,4/5,5` | その場所へ航行を実行 |
| `warp 5` | ワープ係数を5に設定 |
| `move 90 1` | 右へ1宙域ぶん航行 |
| `move 0 0.1` | 上へ1区画ぶん航行 |
| `impulse 90 0.1` | インパルスで右へ1区画ぶん航行 |
| `shields down` | シールドを下げる |
| `shields up` | シールドを上げる |
| `phasers automatic 1000` | 1000エネルギーを使う自動フェイザー射撃 |
| `torpedo 90 no` | 右向きに魚雷を1発発射 |
| `torpedo 90 yes 5` | 右向きを中心に5度間隔の3発発射 |
| `damages` | 故障・修理所要時間を確認 |
| `rest 0.2` | 0.2宇宙日待機し修理・回復を進める |
| `dock` | 隣接する基地へ接舷し補給 |
| `undock` | 基地から出航 |
| `cloak up` / `cloak down` | 遮蔽装置の起動／停止 |
| `capture` | 敵艦に降伏を要求 |
| `dump` | セーブする |
| `terminate` | 現ゲームを終了し、次のゲームを行うか尋ねる |

針路は **0度=上、90度=右、180度=下、270度=左** です。
距離は宙域単位で、0.1が1区画、1.0が1宙域です。

詳細スキャンの記号は `E`=Enterprise、`K`=敵艦、`#`=基地、`*`=恒星、
`@`=居住星系、`.`=空間、空白=ブラックホールです。
長距離スキャンの3桁は「敵艦数・基地数・恒星数」で、`205` なら敵艦2、基地0、恒星5です。

### 戦闘の進め方

`computer trajectory` で敵艦への方向を調べ、魚雷を使うか、
`shields down` の後に `phasers automatic 数値` で攻撃します。
原作の制約により、シールドが上がっている間はフェイザーを撃てません。
魚雷はシールドを上げたまま撃てますが、狙いがぶれやすくなります。
フェイザーは同じ宙域内の敵艦だけに届き、距離が遠いほど効きが落ちます。
敵艦がいる宙域で時間やエネルギーを使う行動をすると、敵も攻撃します。

`help` はコマンド一覧ではなく、基地へ緊急救援を求めるコマンドです。
一覧を見る場合は **`?`** を使ってください。
基地 `#` の隣（斜めを含む）まで移動して `dock` すると、
エネルギー、シールド、魚雷などが補給されます。

## セーブと再開

ゲーム中に `dump` を入力すると、展開フォルダ内に `trek.dump` が作られます。
セーブしてもゲームは続きます。終える場合は `terminate`、続く `Another game:` に `no` と入力します。

次回は起動後、Returnを押し、`What length game:` に **`restart`** と入力します。
新しい長さ・難易度・パスワードの入力は必要ありません。
セーブファイルは1個で、再び `dump` すると上書きします。
同じビルド・同じ環境での再開を想定しています。他版のTrekのセーブとは互換性がありません。
展開フォルダを移すときは `trek.dump` も一緒に移してください。

## 移植内容

元ソース:
https://cdn.netbsd.org/pub/NetBSD/NetBSD-current/src/games/trek/

2026-10-12に取得したNetBSD-current版を固定して同梱しました。
Linuxの `bsdgames` パッケージとも同じBSD Trekの系列ですが、配布版ごとの差はあります。

変更は次のとおりです。

- NetBSD固有の識別マクロ・属性、乱数上限、浮動小数点ヘッダを `src/compat.h` で補います。
- BSD専用Makefileを、Apple Clang／通常のmakeで使えるMakefileに置き換えます。
- `src/dumpgame.c` のセーブ方式を変更します。元版が保存していたアドレスをイベント番号へ変換し、
  ASLRでアドレスが変わる別プロセスでも再開できるようにしました。
  時間ワープ用スナップショットも同様に処理し、保存失敗時に既存セーブを失わないよう一時ファイル経由で更新します。
- 起動用zshスクリプトと、この日本語ガイドを追加します。

戦闘、航行、敵AI、イベント、スコア、難易度の計算処理は元のCソースのままです。
元の各ファイルの著作権・BSDライセンス表示を残しています。
原作由来の挙動や不具合をすべて修正するものではありません。

## 確認した範囲

- Linux上のGCCによるC11ビルド。
- 新規ゲーム、状態表示、長距離スキャン、銀河図、針路照会、ワープ、
  シールド操作、インパルス航行、休息、魚雷発射、終了。
- 保存と別プロセスからの再開。
- 時間ワープ用スナップショットを含むイベント参照の再構築。
- 不完全・異なる形式の保存ファイルを拒否し、現在の状態を壊さないこと。
- zsh起動スクリプトの構文と実行。

利用者のMacで起動したとの報告があります。ただし、そのMacのmacOSバージョンと
CPU種別は未記録です。作成環境ではmacOS実機での検証を行えておらず、
macOS各バージョンおよびIntel／Apple Silicon両方での対応確認は完了していません。

開発用の回帰テストは、Python 3がある環境で `python3 tests/check.py` と実行できます。
ゲームのプレイ自体にPythonは使いません。

## 内容物

- `src/`：原作Cソース、セーブ互換修正、互換ヘッダ。
- `Makefile`：ビルド定義。`make` でビルド、`make clean` で実行ファイルのみ削除。
- `run-trek.zsh`／`Trek.command`：起動スクリプト。
- `trek.6`：原作のmanページ。`man ./trek.6` で表示できます。
- `docs/trek.me`：Eric Allmanによる原作マニュアルのroffソース。
- `docs/UPSTREAM-SHA256.txt`：取得時の原作ファイルのハッシュ一覧。
- `docs/PORT.patch`：原作 `dumpgame.c` からの差分。
- `docs/UPSTREAM-Makefile`：原作のビルド定義。
- `tests/`：移植箇所の回帰テスト。
- `LICENSE.txt`：BSD 3-Clauseライセンス。

手動で直接起動する場合は `make` の後に `./bin/trek` と入力してください。
起動スクリプトを通すとセーブ先は常に展開フォルダになり、
実行時のカレントディレクトリに左右されません。
